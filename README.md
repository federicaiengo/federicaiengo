## Featured Projects

### [E-Commerce Revenue & Operations Analytics](https://github.com/federicaiengo/data-analytics-portfolio/tree/main/projects/ecommerce-revenue-operations-analytics)
**Snowflake · dbt · Python · Power BI**

An end-to-end analytics pipeline using nine e-commerce datasets, with **28 dbt models**, **249 passing regression checks**, incremental ELT and financial reconciliation. An investigation identified **303 mismatches among 98,665 comparable orders**. Project results and limitations are documented in the repository.

### [Insurance Claims Analytics](https://github.com/federicaiengo/data-analytics-portfolio/tree/main/projects/insurance-claims-analytics)
**PostgreSQL · SQL · Tableau**

Relational analysis of a **10,000-claim source dataset**, including data validation, financial exposure, concentration metrics and an executive dashboard. The repository documents which results can be independently reconstructed from the files currently published.

### [HR Analytics: Employee Attrition](https://github.com/federicaiengo/data-analytics-portfolio/tree/main/projects/hr-analytics-employee-attrition)
**SQL · SQLite · Python · Excel**

Analysis of **1,470 employee records**, with a cleaned dataset, data-quality checks, grouped metrics and a documented Excel evidence dashboard. Source reconstruction and automated tests are available; desktop Excel visual compatibility is not claimed as verified.

### [AI Search Visibility Lab](https://github.com/federicaiengo/data-analytics-portfolio/tree/main/projects/ai-search-visibility-lab)
**Python · GEO / AEO · Citation Analysis**

Research tooling for structured, repeatable analysis of AI-generated mentions, citations and source evidence. The published checks validate software behavior and synthetic examples—not measured improvements in real-world search visibility.

### [Cyber Risk & IAM Decision Study](https://github.com/federicaiengo/data-analytics-portfolio/tree/main/projects/cyber-risk-iam-decision-study)
**Python · Identity & Access Management · Risk Analysis**

An independent educational case study using fictional scenarios and synthetic identities to examine supplier access, authorization decisions and risk documentation. It is not presented as a production security audit.
